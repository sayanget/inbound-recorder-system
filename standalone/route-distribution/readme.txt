================================================================
  流向分布工具 (Route Distribution Tool) —— 部署说明
================================================================

适用范围：把本目录打包成一个双击即用的 Windows 工具，发给
          调度组同事使用。数据源可在启动后随时切换：
          - API 模式     →  出库系统的 /api/outbound/records
          - Google Sheet →  CNO Daily 卡车提货信息表 CSV 导出

详细说明见 README.md；本文只保留最常用的部署步骤。


----------------------------------------------------------------
  一、三种部署方案，按你的场景挑一条走
----------------------------------------------------------------

[方案 A] 便携零环境分发（推荐，接收方电脑什么都不用装）
[方案 B] 开发者自己本机调试 / 已装 Python
[方案 C] 终端用户电脑没 Python 又没打包好的 zip，用 setup.bat 自动装


================================================================
  方案 A : 便携零环境分发  <-- 最常用
================================================================

优点：
  - 接收方电脑不需要 Python、不需要联网、不需要管理员
  - 把一个 zip 包发过去，解压 → 双击 build.bat → 出 exe

前提：你本机能上网（只第一次需要，下 Python 3.12 embeddable）。

-----------------------------------------------------------------
第 1 步：一次性初始化便携环境（只做一遍）
-----------------------------------------------------------------
  打开 cmd，cd 到本目录，执行：

    init_portable.bat

  它会：
    - 下载 Python 3.12 embeddable (约 12 MB)
    - 在 portable\ 目录里装齐 flask / requests / pyinstaller / Pillow
    - 整个 portable\ 约 90 MB
  
  完成后你会看到 portable\python.exe 存在。


-----------------------------------------------------------------
第 2 步：打包成分发 zip
-----------------------------------------------------------------
    pack_distribution.bat

  产物：
    ..\流向分布工具-便携版-<时间戳>.zip  (约 24 MB)

  这个 zip 就是给最终用户的。


-----------------------------------------------------------------
第 3 步：接收方使用
-----------------------------------------------------------------
  1. 解压 zip 到任意位置，例如 D:\流向分布工具\
  2. 进入解压出的文件夹，双击 build.bat
     - 约 30 秒后出现 dist\流向分布工具.exe
  3. (可选) 双击 create_shortcut.bat，桌面生成带图标的快捷方式
  4. 双击 流向分布工具.exe 或桌面快捷方式启动

  首次启动会：
    - 随机挑一个可用端口 (9090+)
    - 自动打开默认浏览器 → http://127.0.0.1:<端口>/
    - 在 exe 同目录生成 config.txt 记录数据源


================================================================
  方案 B : 开发者本机  (已装 Python 3.9+)
================================================================

  cd standalone\route-distribution
  build.bat            REM 自动 pip install + PyInstaller 打包

  或者不打包，直接跑源码调试：

  python -X utf8 app.py

  常用参数：

  python app.py --port 9091
  python app.py --backend http://10.0.0.5:8080
  python app.py --backend https://docs.google.com/spreadsheets/d/<ID>/edit
  python app.py --no-browser
  python app.py --skip-probe


================================================================
  方案 C : 终端用户自动装 Python + 打包  (setup.bat)
================================================================

  适用于：用户电脑没 Python，而且你没用方案 A 打便携包，
          只把源码目录拷过去了。

  用户双击 setup.bat 即可，它会：
    1. 检测 Python；没装就自动装 Python 3.12 (优先 winget，失败
       回退到 python.org 下载；当前用户模式，不需要管理员)
    2. 测 pypi 连通性，不通自动切清华镜像
    3. 调 build.bat 打包
    4. 询问是否创建桌面快捷方式

  首次 3~8 分钟 (主要是下 30MB Python 安装包 + pip 包)。
  setup.bat 会动系统；方案 A 完全不动系统。


----------------------------------------------------------------
  二、启动后的配置（所有方案共用）
----------------------------------------------------------------

启动后浏览器会打开主页。顶部有一行
  ⚙ 数据源 [API/Sheet]: http://...
点它就进 /setup 页，可以切换：

  [API]         填 http://host:port 形式的后端地址
                可点"开始扫描"自动找局域网出库系统
  [Google Sheet] 填完整 Sheet URL（需先把 Sheet 设为
                "拥有链接的任何人 → 查看者"）
                可填"MM-DD 日期默认年份"，供推断年份用

保存后写入 exe 同目录的 config.txt，下次自动沿用。


----------------------------------------------------------------
  三、config.txt 文件格式
----------------------------------------------------------------

  # 支持 API URL 或 Google Sheet URL，两种都行
  http://192.168.0.250:8080
  # 或
  https://docs.google.com/spreadsheets/d/<ID>/edit#gid=0

  # 可选：MM-DD 日期的默认年份（仅 Sheet 模式用得上）
  year=2026


----------------------------------------------------------------
  四、修改后端地址的四种方式（优先级从高到低）
----------------------------------------------------------------

  1. 命令行参数      流向分布工具.exe --backend http://host:port
  2. 环境变量        set ROUTE_DIST_BACKEND=http://host:port
  3. 设置页 UI 保存  http://127.0.0.1:909x/setup
  4. config.txt      编辑 exe 同目录文件

  IP 经常变的话推荐用主机名 (http://server01:8080)
  或走设置页里的"局域网扫描"按钮。


----------------------------------------------------------------
  五、常见问题
----------------------------------------------------------------

【Q1】 启动时提示"后端不可达"
 → 自动跳到 /setup 页。点"开始扫描"或手动改 URL。

【Q2】 打包完 exe 启动时黑窗口一闪而过
 → 在 cmd 里手动跑 dist\流向分布工具.exe，看报错信息。
   常见是端口被占或 config.txt 写坏了。

【Q3】 Sheet 模式选了区间但调度组模板一片空白
 → 说明那个区间 Sheet 里真的 0 条。顶部黄色提示框会写
   "⚠ 本时间区间 0 条发车记录"。换有数据的区间试。

【Q4】 Sheet 数据全部挤在一年里 / 年份不对
 → Sheet 的 DATE 列只写了 MM-DD，工具会按链式滚动推断年份。
   去 /setup 页 "MM-DD 日期默认年份" 里填对起始年即可。

【Q5】 Sheet 抓取失败 "HTTP 401/403"
 → Sheet 没设公开。打开 Sheet → 共享 →
   "限定对象" 改成 "拥有链接的任何人"。

【Q6】 setup.bat 下载 Python 失败
 → 去 https://www.python.org/downloads/ 手动装，
   勾 "Add to PATH"，重跑 setup.bat。

【Q7】 pip 装依赖超时
 → setup.bat 自动切镜像；如仍慢手动执行：
   pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

【Q8】 浏览器控制台有 unload 违规或 favicon 404
 → unload 违规是浏览器扩展注入的脚本，跟本工具无关，
   隐身窗口打开会消失。favicon 404 已修（升到最新代码即可）。


----------------------------------------------------------------
  六、文件清单
----------------------------------------------------------------

本目录常见文件：

  app.py                  Flask 后端 + 页面渲染
  route-distribution.html 前端页面（打包时会嵌入 exe）
  requirements.txt        Python 依赖清单
  config.txt              运行时数据源配置（启动后自动生成/更新）
  README.md               完整说明（含架构、计数规则、疑难排查）
  readme.txt              本文件（部署速查）

  init_portable.bat       初始化便携 Python 环境
  pack_distribution.bat   打包便携 zip 发给别人
  build.bat               用 PyInstaller 打包 exe
  setup.bat               终端用户一键装 Python + 打包
  create_shortcut.bat     生成桌面快捷方式
  gen_icon.py             生成 icon.ico (构建时用)

构建产物：

  dist\流向分布工具.exe    最终 exe（约 15~25 MB）
  dist\icon.ico            图标（供快捷方式引用）
  portable\                便携 Python + 依赖（~90 MB，方案 A 用）
